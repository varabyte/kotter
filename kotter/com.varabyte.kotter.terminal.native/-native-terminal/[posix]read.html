read

open override fun read(): SharedFlow<Int>(source)

Return a hot SharedFlow which will get triggered with characters read in by the underlying terminal, often input typed in by a user.

Note that these characters may represent encodings for actions, for example LEFT will be the character sequence ESC, [, D.
