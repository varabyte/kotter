CustomFormatScope

class CustomFormatScope(val input: String, val index: Int, val isActive: Boolean)(source)

Information passed into the customFormat callback in the input method.

The callback will be triggered once per character in the input string when it's about to get rendered (excluding any autocomplete suggestion text). The user can then call any of the formatting methods which will be applied to THE CURRENT CHARACTER ONLY.

For an example, to visually highlight all non-digits as invalid (or, red):

input(customFormat = { if (ch.isDigit()) green() else red() })
Content copied to clipboard

The following format will apply an underline to all characters:

input(customFormat = { underline() })
