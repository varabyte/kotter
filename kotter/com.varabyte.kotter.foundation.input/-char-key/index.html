CharKey

class CharKey(val char: Char) : Key(source)

Class for every key with a typeable value, e.g. 'a', '~', '7'

This class is case-insensitive, meaning CharKey('q') will match CharKey('Q'). This allows us to have a DSL that defaults to matching any instance of that key, e.g.:

when (key) {
   // Handles 'q' and 'Q' both
   Keys.Q -> quit()
}

If you need case-specific handling, you can query via isUpper, isLower, or char:

when (key) {
   Keys.Q -> {
      if (key.isUpper()) quit() else confirmThenQuit()
   }
}
